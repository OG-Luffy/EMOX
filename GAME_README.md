# EMOX: Open World — Android Game Foundation

A production-oriented foundation for a realistic third-person open-world Android game.

## What is in this repo
- Game vision and technical direction
- Android performance/build plan
- Development roadmap
- Lightweight vehicle-physics prototype

## Important
This repository is not yet a complete AAA 3D game or installable APK. Full ultra-realistic visuals require an Unreal Engine 5 project plus 3D assets, animation, audio and Android packaging.

## Next production step
Create the Unreal Engine project and implement the vertical slice: streamed terrain + third-person character + drivable vehicle + touch HUD.
