EMOX Privacy Policy

Last updated: September 21, 2026

This Privacy Policy explains what information EMOX processes when it is used in a Discord server.

1. Information Processed

Depending on the features enabled by a server, EMOX may process Discord identifiers such as server IDs, user IDs, channel IDs and usernames, plus message activity needed for features such as XP, economy and AutoMod.

2. Stored Server Data

EMOX may store server configuration and feature data including warnings, XP, economy balances, welcome-channel settings, log-channel settings, AutoMod status, and daily/work cooldown timestamps. The current bot implementation stores this data in its local application data file.

3. Why Data Is Used

The data is used only to provide and operate EMOX features, maintain server configuration, apply moderation settings, and respond to commands.

4. Sharing

EMOX does not sell personal information. Data may be processed by the infrastructure or hosting provider used to operate the bot and by Discord as part of Discord's platform services.

5. Retention and Deletion

Stored data is retained while it is needed for bot functionality. Server administrators can request deletion of EMOX's stored data by contacting the bot owner through the EMOX support/ticket system. Removing the bot from a server may also stop further processing for that server, but previously stored data may require a deletion request.

6. Security

Reasonable measures are used to protect bot data, but no internet-based system can guarantee absolute security.

7. Changes

This policy may be updated when EMOX's features or data practices change. The updated version will be published on this page.

8. Contact

For privacy questions or deletion requests, use the EMOX support/ticket system or contact the bot owner through the Discord community where EMOX is installed.
