# 🤖 EMOX

**One Bot. Everything You Need.**

EMOX is an all-in-one Discord bot built with Node.js and Discord.js.

## Features roadmap

- 🛡️ Moderation
- 🎫 Tickets
- 🎉 Giveaways
- 👋 Welcome / Goodbye
- 📝 Logging
- 🏆 Leveling & XP
- 💰 Economy
- 🎮 Games
- 🤖 AI features
- ⚙️ Server configuration
- 📊 Server statistics
- 🔔 Auto roles

## Current version

The first working skeleton includes:
- Slash command deployment
- /ping
- /help
- Discord client startup
- Environment configuration

## Setup

1. Install Node.js 20+.
2. Run `npm install`.
3. Copy `.env.example` to `.env`.
4. Add your Discord bot token, application/client ID and test server ID.
5. Run `npm run deploy`.
6. Run `npm start`.

Never commit your real bot token.
